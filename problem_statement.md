# Early Fault Detection on Transformer Units**Stream:** Electrical  |  **Task type:** Classification## BackgroundCirrus Electronics manages a fleet of distribution transformers. Field teams want a model that flags units likely to develop a `fault` in the next maintenance cycle, using nameplate data, oil/thermal sensor readings, and load logs, so crews can prioritize inspections.## Your DeliverableBuild a classification model predicting `fault\\\\\\\_status` (Fault/Normal) for each transformer using the transformer registry, oil/thermal readings, and load logs.## Files Provided* `transformer\\\\\\\_registry.csv`* `oil\\\\\\\_thermal\\\\\\\_readings.csv`* `load\\\\\\\_logs.csv`* `fault\\\\\\\_status\\\\\\\_labeled.csv`* `fault\\\\\\\_status\\\\\\\_to\\\\\\\_predict.csv`All tables that share the `transformer\\\\\\\_id` column can be joined on it. Not everyfile is already clean or already in the shape you need -- inspect each onebefore you start modeling.Predictions are required for every `transformer\\\\\\\_id` listed in the`\\\\\\\*\\\\\\\_to\\\\\\\_predict.csv` file (these entities have no label in the training data).## Suggested Steps1. Inspect `transformer\\\\\\\_registry`, `oil\\\\\\\_thermal\\\\\\\_readings`, `load\\\\\\\_logs`; find shared key `transformer\\\\\\\_id`.2. Aggregate oil/thermal and load readings per transformer.3. Merge aggregated features with `transformer\\\\\\\_registry` on `transformer\\\\\\\_id`.4. Handle missing values and outliers in gas/oil readings.5. Encode categorical columns (cooling\_type, zone, rated\_kva).6. Min-max normalize numeric features before modeling.7. Train a classifier for `fault\\\\\\\_status`; predict for ids in `\\\\\\\_to\\\\\\\_predict.csv`.8. Report precision/recall and discuss class imbalance if present.## Notes* At minimum, apply min-max normalization to your numeric features beforemodeling; you're welcome to also explore standardization and compare.* Document your merge keys, cleaning decisions, and any assumptions in yoursubmission.
